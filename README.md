# Форма оценки дизайнов Gresse

Три файла:

| Файл | Что это |
|---|---|
| `index.html` | сама форма (та же логика, что у вас была: розница/опт, фавориты, отправка) |
| `tiles.js` | список вариантов из вашего Excel — 88 позиций |
| `xlsx_to_tiles.py` | скрипт, который заново собирает `tiles.js` из Excel вместе со ссылками на фото |

---

## 1. Что уже сделано

Из листа **«Опросник»** вытащена иерархия по отступу в колонке A:

- уровень 0 (`Бетоны`, `Дерево`, `Камень`, `Оникс`, `Травертин`) → **раздел**
- уровень 1 (`ARENISCA`, `MOON`, `TEJIDO`…) → **коллекция**
- уровень 2 (`ARENISCA 1`, `MOON CHOCO`…) → **вариант, становится карточкой**

Итого **88 карточек**:

| Раздел | Коллекций | Вариантов |
|---|---|---|
| Бетоны | 4 | 30 |
| Дерево | 1 | 1 |
| Камень | 3 | 21 |
| Оникс | 5 | 20 |
| Травертин | 3 | 16 |

То есть колонки «Имя 1…Имя 5», «Средний балл» и «Комментарии» в форму не переносятся —
их роль выполняет сама форма: оценки уходят в Google-таблицу, где вы и считаете средние.

## 2. Про ссылки на картинки — важно

Колонка **«Изображение»** в текстовой выгрузке пустая. Это нормально: Excel хранит
такие ссылки как **гиперссылки ячейки**, а не как текст, поэтому в простом тексте
их не видно. Достать их можно только из самого `.xlsx` — этим и занимается
`xlsx_to_tiles.py`.

Вторая колонка, **«Все изображения»**, содержит «10 фото» — судя по всему, там
ссылка на **папку** на Яндекс.Диске, а не на один файл.

### Как получить ссылки

```bash
pip install -q openpyxl requests

# 1. Просто вытащить ссылки
python xlsx_to_tiles.py "Опросник.xlsx"

# 2. + развернуть папки Яндекс.Диска в список картинок (их можно листать в лайтбоксе)
python xlsx_to_tiles.py "Опросник.xlsx" --expand-folders

# 3. + скачать фотографии в ./images (форма будет работать быстро и без чужих серверов)
python xlsx_to_tiles.py "Опросник.xlsx" --expand-folders --download
```

Скрипт напишет, сколько вариантов нашли превью, и перечислит те, где ссылки нет —
по ним вы поймёте, где в Excel пропущена гиперссылка.

Скрипт распознаёт:

- обычные гиперссылки ячейки;
- формулу `=HYPERLINK("url";"подпись")`;
- просто URL, написанный текстом;
- прямые ссылки на изображения (`.jpg`, `.png`, `.webp`…) → идут в `image`;
- ссылки на папки/страницы (`disk.yandex`, `yadi.sk`, Google Drive) → идут в `link`,
  а с ключом `--expand-folders` разворачиваются в список картинок.

## 3. Что добавлено в форму

Логика отправки, фавориты и шкалы — как в вашем исходнике. Новое:

1. **Группировка «раздел → коллекция → вариант»** — точно как в Excel.
2. **Поиск** и **фильтр по разделу** (чипы сверху) — при 88 карточках без этого тяжко.
3. **Лайтбокс-галерея**: если у варианта несколько фото, стрелки ‹ › и счётчик «3 / 10»,
   плюс кнопка «Все фото →» на папку Яндекс.Диска. Управление: Esc, ←, →.
4. **Плашка «10 фото»** на превью, если картинок несколько.
5. **Колонка сетки** адаптивная: 3 в ряд на широком экране, 2 на планшете, 1 на телефоне.
6. **Блокировка кнопки «Отправить»** поправлена: теперь она активна, если есть
   хотя бы оценки *или* фавориты (в исходнике счётчик `done === 0` смотрел на оценки,
   из-за чего при одном только фаворите кнопка оставалась серой).
7. Подписи шкалы приведены к формулировкам Excel:
   *не нравится / скорее нет / нейтрально / нравится / очень нравится*.

## 4. Как развернуть

1. Положите рядом `index.html`, `tiles.js` и папку `images` (если качали фото).
2. В `index.html` в самом верху скрипта проверьте `window.SCRIPT_URL` — там уже стоит
   ваш адрес Google Apps Script из исходной формы. Если таблица другая, замените.
3. Откройте `index.html` в браузере или залейте на любой хостинг
   (GitHub Pages, Netlify — просто перетащите папку).

Отправка идёт через `sendBeacon` с запасным `fetch(mode:"no-cors")` — CORS не мешает,
как и в исходном варианте.

## 5. Мелочи, о которых стоит знать

- **Локальные пути к фото.** Если запустить `--download`, то `tiles.js` будет ссылаться
  на `images/….jpg`. Это работает, пока `images` лежит рядом с `index.html`. Хотите
  один самодостаточный файл — не запускайте `--download`, пусть ссылки будут внешними.
- **Ссылки Яндекс.Диска не всегда годятся как `src` картинки.** Публичная страница
  файла — это HTML, а не изображение. Скрипт для таких ссылок использует `preview`
  из API Диска; если превью не отдаётся, карточка покажет «[ссылка на фото]»
  и будет кликабельной. Именно поэтому `--download` — самый надёжный путь.
- **Порядок сортировки** внутри коллекции — как в Excel. Вариант без номера
  (`ARENISCA`) идёт первым, нумерованные — за ним.
- **Поле `abc`** в `tiles.js` оставлено пустым и не используется: в этом Excel
  колонки A/B/C нет. Если появится — форма сама отсортирует по ней.
